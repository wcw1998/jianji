# 鉴己 · 笔记洞察

用免费/本地模型复刻 flomo Pro 的那 6 个 AI 洞察：默认洞察、价值澄清、逆向思考、二阶思考、CBT 疗法、MBTI 分析。

**核心逻辑**：这类 AI 洞察卖的不是模型，是提示词 + 你的数据。数据是你的，提示词这包东西现在归你了。

## 三步跑起来

### 1. 导出笔记

flomo 网页版 → 左下角「设置」→「导出」→ 选 **HTML** 或 **CSV**（免费版就能导全量）。
HTML 保留格式和标签更完整，CSV 更好处理，两个都行。

### 2. 拿一个免费模型接口

任选一个，都注册即用：

| 服务商 | 免费情况 | 模型名 |
|---|---|---|
| **智谱开放平台** bigmodel.cn | `glm-4-flash` / `glm-4.5-flash` 长期免费 | `glm-4-flash` |
| **硅基流动** siliconflow.cn | 部分小模型免费 | `Qwen/Qwen2.5-7B-Instruct` |
| **DeepSeek** platform.deepseek.com | 无免费额度，但便宜到几乎可忽略 | `deepseek-chat` |
| **本地 Ollama** | 完全免费，数据不出本机 | `qwen2.5:7b` |

> 免费额度和模型名会变，以各家官网当前页面为准。

### 3. 开跑

**方式 A：桌面版（PyQt6 壳，推荐）**

双击 **`dist/jianyi-qt/jianyi-qt.exe`** → 独立窗口打开（QWebEngine 内置 Chromium，无需浏览器）→ 自动起 Python 代理并选空闲端口 → 点右上「模型设置」填接口 + Key + 模型名 → 导入文件 → 选洞察 → 生成。关窗口自动清理代理。

整个 `dist/jianyi-qt/` 文件夹拷到别的机器即可分发（**目标机无需装 Python**：包内带 `runtime/` 嵌入式 Python，降级与 CLI 都可用）。
重新打包：`python -m PyInstaller jianyi_qt.spec --noconfirm --clean`。
开发模式：`python desktop_qt/main.py`（需先 `pip install PyQt6 PyQt6-WebEngine`）。

**方式 B：浏览器版**

双击 **`start.bat`** → 浏览器自动打开 `http://localhost:8000` → 标题右边出现绿色「本地代理已启用」→ 点右上「模型设置」填接口地址 + Key + 模型名 → 导入导出文件 → 选洞察 → 生成。

手工启动等价于：

```bash
python server.py 8000
```

**方式 B：命令行**

```bash
# 看有哪些维度
python jianyi_insight.py --list

# 跑一个：最近 90 天的默认洞察
set JIANI_AI_KEY=你的key
python jianyi_insight.py -f flomo.csv --mode 默认洞察

# 六个一次跑完，输出到 ./jianyi-insights/
python jianyi_insight.py -f flomo.html --all

# 只打印提示词，不花 token
python jianyi_insight.py -f flomo.csv --mode cbt --dry-run

# 本地 Ollama，零成本
python jianyi_insight.py -f flomo.csv --all ^
  --api-base http://localhost:11434/v1/chat/completions --model qwen2.5:7b
```

常用参数：

```
-f/--file      导出文件（CSV / HTML / txt）
-m/--mode      insight | value | invert | second | cbt | mbti，也可写中文名
--all          六个洞察一次跑完
-d/--days      只分析最近 N 天（默认 90，0 = 全部）
--max-chars    单次送入上限，默认 18000
--dry-run      只打印 prompt
```

## 三种白嫖姿势，按投入排序

**姿势一：完全不写代码**
打开 `prompts.md`，复制某段提示词 + 你的笔记，粘到 DeepSeek / Kimi / ChatGPT 网页版里。一分钱不花，效果和大厂 Pro 功能没差。

**姿势二：网页版（推荐）**
`index.html` 已经把这些手工步骤都封装好了，导入导出文件就自动切分和过滤时间段。缺点是要自己填一次 API Key。

**姿势三：全自动**
用 `jianyi_insight.py` 挂 Windows 计划任务，每月 1 号自动跑一次上个月的六维洞察，落到 `jianyi-insights/` 目录。配置参考：

```
程序:   python
参数:   jianyi_insight.py -f D:\flomo.csv --all -d 30 -o D:\insights
起始于: D:\jianyi
```

再配合 Obsidian / 坚果云同步那个目录，相当于每月自动收到一份「自己的月度诊断」。

## 输出格式：论文式引用

洞察正文不摘抄笔记原文，所有证据以**编号上标** `[n]` 出现在结论句末尾（像论文的文献引用）：

- 悬停编号 → 浮出对应笔记的日期和内容
- 点编号 → 底部「引用的笔记」清单展开并高亮那条
- 「复制结果」会把正文 + 引用笔记清单一起复制走
- 编号是真实的：模型只能引用你实际提供的笔记，引用不存在的编号不会被渲染成假引用

这条规则写在通用提示词里，六个洞察全部生效，自己新建的洞察也自动继承。

## 怎么调优洞察结果

**入口：右上角「调优洞察」**。可视化编辑全部提示词，保存后主界面立即生效，不用碰代码。

- 6 个默认洞察可以改（改过会标「已调优」，随时可一键恢复默认）
- 「＋ 新增洞察」可以造你自己的维度（比如「决策复盘」「情绪周期」），带提示词骨架
- 「导出配置 / 导入配置」：调优结果存在浏览器本地，**换设备不会自动跟过去**，用这两个按钮带走

### 四个最见效的调法（按性价比排序）

**1. 改语气和立场**（默认是"了解你的朋友"）
在提示词的【角色】里换人称。例：把"像一个了解你的朋友"换成"像一个不接受任何借口的项目复盘主持人"，输出会立刻变锋利；换成"像一个耐心的教练"则更温和。一处改，全局变。

**2. 加聚焦范围**（默认什么都看）
在【任务】前加一行：`只关注和工作/决策相关的笔记，情感和日常记录只做背景参考。` 分析会更深而不是更散。

**3. 改输出结构**
- 想要打分：加 `给每个模式标注出现频率（高/中/低）和影响程度（1-5 分）`
- 想要表格：加 `最后用一个 Markdown 表格汇总所有结论，列：模式 / 证据数 / 首次出现 / 最近出现`
- 觉得太长：把 800 字上限改成 500，并加 `每个模式最多引用 1 条原文`

**4. 做时间对比**（强烈推荐）
复制「默认洞察」，名字改成「月度对比」，任务改成：
```
我会给你两份笔记：本月和上月。对比分析：
1. 哪些模式在消失（进步）
2. 哪些模式在加强（警报）
3. 这个月新出现了什么
4. 用一句话判断：这个月的我，在往哪个方向走
```
然后每月导出一次，两份分别粘贴，固定跑这一个。这比单次分析有用得多——单次看状态，对比看趋势。

### 调优的两条底线

1. **别删"必须引用原文+日期"**。删了之后 AI 会开始编造你的心理活动，看起来更深，其实是幻觉。
2. **别加"请更深入地分析"**。这种正面要求基本无效，"深入"的正确写法是具体动作：`对每个结论追问一个"为什么"并给出笔记中的证据`。

## 怎么喂资料让它更专业

**核心结论：喂什么比喂多少重要得多。** 喂一本 CBT 教材，模型只会用更专业的词说同样模糊的话；喂一张判定表，它才会真的去分类。

按性价比排序，只有前三层值得喂：

| 喂什么 | 效果 | 篇幅 |
|---|---|---|
| **判定标准 / 评分规则**（谁算、怎么判、几级） | 最高 | 短，几百字 |
| **2–3 个优质范例**（你认可的真实输出） | 很高 | 中 |
| **反例黑名单**（"不要写成这样"） | 很高 | 短 |
| 理论原文 / 整本书 | 很低，模型会划水 | 长 |

### 已经给你写好的 7 份资料包（`knowledge/`）

| 文件 | 内容 | 用途 |
|---|---|---|
| `00-通用判定原则.md` | 证据分级 A/B/C/D、模式成立三条件、巴纳姆黑名单、术语与语气纪律 | 所有洞察共用，**最该先开这个** |
| `01-默认洞察…` | 9 种思维模式的句式识别 + 代价 + 4 类内在矛盾 | 把"你很矛盾"变成"是哪两股力在拉扯" |
| `02-价值澄清…` | Schwartz 十类价值观 + 四条证据链 + 相邻/对角冲突 | 把"你在意成长"变成可排序的具体价值 |
| `03-逆向思考…` | 10 种误判倾向 + 6 个失败模式 + 建议的三个硬条件 | 防"提升效率"式空话 |
| `04-二阶思考…` | 三层结构 + 四种维持收益 + 增强/调节回路 + 供养判定 | 专业度分水岭在这一份 |
| `05-CBT…` | 11 种认知扭曲判定表 + 反证排序 + 苏格拉底提问 + 安全边界 | 有明确的安全红线（自伤/两周功能受损不分析只提示） |
| `06-MBTI…` | 八种认知功能的行为标记 + 四场景判定 + 五类误判源 + 置信度规则 | 防星座式夸赞 |

### 三种喂法

1. **一键载入**（最快）：右上「调优洞察」→ 选一个洞察 → 资料下拉选对应资料包 → 「载入」→ 保存。
   通用资料在「模型设置」最下方，点「载入内置通用原则」。
2. **导入自己的文件**：资料区「导入文件」，支持 `.md` / `.txt`。
3. **改内置资料**：直接编辑 `knowledge/*.md`，然后 `python build_knowledge.py` 重新生成 `knowledge.js`，刷新页面生效。命令行版直接读 `knowledge/` 目录。

### 三个硬规则（不遵守就白喂）

1. **资料要声明优先级**：工具已经在拼接时自动加了「判定标准以本段为准，不要引用资料中没有的术语」。自己写资料时也要带这类话，否则模型会把资料当参考读物。
2. **单块控制在 3000 字以内**：超过 6000 字会明显稀释注意力（工具会自动截断并在末尾标注）。想要更多知识，应该压缩成规则，不是堆原文。
3. **名词必须配行为标记**：写「回避型延迟」没用，写「句式信号：等信息更全 / 等时机成熟；判定要点：信息已够用，真实原因是选择不可逆」才有用。

命令行版：

```bash
python jianyi_insight.py -f flomo.csv --all              # 自动加载 knowledge/
python jianyi_insight.py -f flomo.csv --all --no-kb      # 不带资料，对比效果
python jianyi_insight.py -f flomo.csv --kb 我自己的资料.md  # 用自己的资料替代
```

## 提示词为什么这么写

三条设计原则，改提示词的时候别删：

1. **强制引用原文+日期**：所有结论必须有证据。不加这条，AI 会顺着你的情绪编。
2. **强制给反证**：CBT 要求用你自己写过的话反驳你；MBTI 要求每个维度都给反证据和"最可能的误判点"。不加这条，AI 会一路夸你。
3. **负面约束比正面要求有效**：明确写「不要给行动建议」「不要写正确的废话」「证据不足就说线索太弱」，比写「请深入分析」有用得多。

另外，**洞察类分析用 30–90 天窗口效果最好**。跨度太长会被人生阶段变化稀释，太短看不出反复。想看变化，就固定 90 天窗口按月跑，横向对比。

## 为什么必须用它（`Failed to fetch` 的真相）

浏览器有个安全机制：`localhost:8000` 上的页面用 JS 去请求 `open.bigmodel.cn` 的接口，属于跨域，对方必须在响应头里明确写 `Access-Control-Allow-Origin` 才会放行。

实测智谱接口的预检响应里**没有**这个头：

```
$ curl -i -X OPTIONS https://open.bigmodel.cn/api/paas/v4/chat/completions \
    -H "Origin: http://localhost:8000" -H "Access-Control-Request-Method: POST"

HTTP/1.1 200 OK
Vary: Origin
（无 Access-Control-Allow-Origin）
```

所以不管你双击 `index.html`（file://）还是用 `python -m http.server`（localhost），**都会被浏览器拦下来**，报 `Failed to fetch`。这跟 Key 对不对、网络通不通都无关。

`server.py` 的解法：页面把请求发给同源的 `/__proxy`，本机 Python 再转发给目标接口。对浏览器来说全程同源，不触发 CORS；上游的状态码、错误信息、流式数据全部原样透传。

已实测验证：
- 上游 401 → 原样返回 `401 + {"error":{"code":"401","message":"令牌已过期或验证不正确"}}`，页面上能直接看到真实原因
- SSE 流式响应 → 逐块转发不缓冲（4 个分片按 0.25s 间隔到达，总耗时 1.0s，确认没被攒成一坨）

## 隐私说明

- 网页版只把笔记发给你自己配置的那个接口，本工具不上传任何服务器，没有后端。
- 但笔记一定会进入模型上下文。如果内容很私密，用 **本地 Ollama**，数据完全不出机器。
- API Key 存在浏览器 localStorage 里（网页版），或环境变量里（命令行），代码里没有硬编码也没有回传。
