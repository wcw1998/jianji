鉴己 · 快速上手（3 步，约 5 分钟）
================================

【第 0 步】装 Python（装过就跳过）
  https://www.python.org/downloads/ 下载安装。
  安装时务必勾选 "Add python.exe to PATH"。

【第 1 步】启动
  双击 start.bat
  浏览器会自动打开 http://localhost:8000
  页面标题出现绿色「本地代理已启用」= 正常。

【第 2 步】配置模型（每台设备只需做一次）
  右上角「模型设置」：
  - 服务商选「智谱 GLM」
  - 模型名填 glm-4-flash
  - API Key 填你的智谱密钥（open.bigmodel.cn 控制台创建）
  然后「导入导出文件」上传 flomo 导出的 CSV 或 HTML，
  选一个洞察，点「生成洞察」。

常见问题
--------
· 双击 start.bat 一闪而过？
  → 没装 Python，或安装时没勾 "Add python.exe to PATH"。
· 报"请求失败"？
  → 看红色提示框的具体内容，通常会写清楚是 Key 错还是地址错。
· API Key 会不会跟着这个文件夹走？
  → 不会。Key 保存在各设备浏览器的本地存储里，
    换设备要重新填一次（一次就好）。
· 笔记数据在哪？
  → 在 flomo 官方导出的文件里，本工具不发往任何第三方，
    只发给你自己配置的模型接口。想更彻底就用本地 Ollama。

命令行玩法（可选）
------------------
  python jianyi_insight.py --list            看有哪些洞察维度
  python jianyi_insight.py -f 笔记.csv --all  六个洞察一次跑完
  python jianyi_insight.py --help            完整说明
