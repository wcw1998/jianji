# 逆向思考 · 误判心理学与失败模式判定

## 一、方法内核

芒格：**反过来想，总是反过来想。**
不问"怎么成功"（成功因素不可穷举、不可复制），只问"什么会让我必然失败"（可枚举、可规避）。
专业与业余的区别：业余找加速器，专业找致命伤。

## 二、十种最容易致命的误判倾向（按笔记可识别度排序）

1. **承诺与一致性倾向**：为了让过去的选择显得正确，继续投入。信号：「都已经…了」「不能白费」
2. **沉没成本谬误**：用已付出的量决定未来，而非用未来收益决定未来。
3. **避免不一致倾向（自我形象保护）**：宁可事实错，也不承认判断错。信号：把质疑描述为"别人不懂"
4. **社会认同倾向**：用同龄人的进度校准自己的选择。信号：比较后立刻找理由（"他有资源"）
5. **奖励超级反应**：激励结构决定行为。信号：反复做"有人看见才有价值"的事
6. **简单避免痛苦的心理否认**：把难以承受的事实写成轻描淡写的一句。信号：重大事件 + 极轻措辞
7. **过度乐观倾向**：只估算顺利路径，不给失败留预算。信号：计划里没有 Plan B 的痕迹
8. **剥夺性超级反应**：对"失去已有的"的恐惧远大于"获得更好的"的渴望。信号：守着不满意的现状
9. **易得性误判**：用最近看到的案例（别人创业成功/裁员的新闻）判断概率。
10. **压力影响倾向**：高压下动作变形，做出一致性更强的决定（更保守或更极端）。

## 三、六个高频失败模式（对每个目标套用）

| 模式 | 判定条件 | 笔记里的早期信号 |
|---|---|---|
| 承诺升级 | 继续投入的理由是过去投入 | 「两年了」「白费」 |
| 单点依赖 | 目标成立完全依赖一个不可控条件 | 「等 XX 定了再说」 |
| 无退出条件 | 从没写过"什么情况下我放弃" | 只有 IF 成功，没有 IF 失败 |
| 手段变目的 | 在辅助动作上投入超过主目标 | 改文档三遍，但决定没做 |
| 忙碌替代判断 | 用可完成的琐事回避不可完成的选择 | 忙完之后问题还在 |
| 运气当能力 | 成功归因于自己，失败归因于环境 | 双向归因不对称 |

## 四、输出规则

对每个识别出的真实目标（**行为指向的目标，不是笔记里写的目标**）：
1. 列 5 个失败原因，每个必须能指回一条原文（不许列通用风险清单）
2. 标注：已出现（引用）/ 尚未出现（这是安全边际）
3. 给一个"避免愚蠢"动作，三个硬条件：
   - **可逆**（做错了能撤回）
   - **低成本**（不需要意志力，一天内能完成）
   - **具体到动作**（"写下放弃条件"可以，"提升判断力"不行）

## 五、禁止事项

- 不许出现这些建议：提升效率、坚持复盘、保持学习、多沟通、早点睡
  检验方法：把主语换成任何一个人，如果这句话仍然成立，就删掉。
- 不许把目标写成愿望。愿望是"我想变好"，目标是"时间与钱流向的地方"。
- 不许给三条以上建议。逆向思考的产出应该是"少做什么"，不是"多做什么"。
