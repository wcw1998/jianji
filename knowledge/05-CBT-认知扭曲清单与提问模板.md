# CBT · 十一种认知扭曲判定表与重构标准

## 一、判定表（先匹配句式，再定类型）

| 类型 | 定义 | 笔记里的典型句式 |
|---|---|---|
| 非黑即白 | 只有两档，没有中间 | 「要么…要么…」「如果做不到就是失败」 |
| 过度概括 | 一次当永远，一事当全部 | 「总是」「从来」「每次都」「我就是这种人」 |
| 心理过滤 | 只看负面，过滤正面 | 全天顺利，只写那一件错的 |
| 否定正面 | 好事被解释为不算数 | 「那是因为运气/简单/别人帮忙」 |
| 读心术 | 断定别人在想什么 | 「他肯定觉得我…」「他们其实都看得出来」 |
| 预言灾难 | 直接跳到最坏结果 | 「这样下去就完了」「以后都没法…」 |
| 放大与缩小 | 放大缺点，缩小优点 | 错误用重词，成绩用轻词 |
| 情绪化推理 | 我感觉如此，所以事实如此 | 「我觉得自己很糟，所以我确实很糟」 |
| 应该式 | 用"应该"审判自己和他人 | 「我应该早就…」「别人不该…」 |
| 贴标签 | 用整体标签代替具体行为 | 「我是个失败者」「他很自私」 |
| 个人化 | 把不可控的事归因于自己 | 「都怪我没…」 |

判定优先级：先看**绝对化词**（总是/从不/必须），再看**归因方向**（向内还是向外），最后看**结果跳跃**（是否直接跳到最坏）。

## 二、反证义务（这是 CBT 区别于鸡汤的地方）

每处扭曲必须给反证，反证来源按可信度排序：
1. **用户自己写过的相反事实**（最强——用他的话反驳他）
2. **同一份笔记里的例外**（"总是搞砸"但上周写了一条成功）
3. **行为证据**（说没人喜欢自己，但记了三次聚会）
4. **概率常识**（"绝对会失败"→ 实际概率）

如果找不到反证，明写「暂无反证，但该结论的证据也只有一条」。不许为了好看编造正面事件。

## 三、苏格拉底式提问模板（写反证时用）

- 支持这个想法的**证据**是什么？反对的证据是什么？
- 有没有**第二种解释**？
- 最坏、最好、**最可能**分别是？
- 如果是朋友这样对我说，我会怎么回他？
- 一年后回看，这件事会有多重？

## 四、重构句式的三条标准（不合格就重写）

1. **具体**：有时间和数量（"这周三件里搞砸两件"，不是"有时会出错"）
2. **可检验**：能被未来的事实推翻
3. **保留情绪合理性**：不是把负面改成正面，而是把绝对改成准确

示范：
- 原句：我总是搞砸。
- 不合格：我其实很优秀。（否认情绪）
- 合格：这周三件事我搞砸了两件，周四那次我做对了；我在这类任务上确实慢，但不是"总是"。

## 五、安全边界（必须执行）

- 只做认知层面的识别，不做诊断、不评估病程、不建议停药或用药。
- 出现以下内容时，**不分析、只提示求助**：自伤/自杀表述、持续两周以上的功能受损（无法工作、无法入睡、无法进食）、现实检验受损（幻听、被害想法）。
- 结尾固定一行：这不是心理治疗。若这种状态持续两周以上，请找专业人士。

## 六、禁止事项

- 不许一次列出五条以上扭曲（人会防御，3 条以内才听得进去）。
- 不许把正常的负面情绪当扭曲（难过、生气不是扭曲，扭曲是**推理方式**出错）。
- 不许用"你要积极一点""换个角度看"作为建议。
