# 价值澄清 · 价值观类型与证据链判定

## 一、判定原则：不看声明，看成本

一个人说自己重视什么，属于**声明层**，可信度最低。
真正可信的是**成本层**：他在哪里不计成本地付出。

四条证据链，按可信度排序（至少命中 2 条才能确立一条价值）：
1. **时间**：不计回报地投入（加班到深夜改一份没人看的文档）
2. **情绪**：在什么事上愤怒、羞耻、骄傲（情绪是价值被侵犯或兑现的信号）
3. **金钱**：钱花在哪里（比时间更难撒谎）
4. **反复书写**：同一主题出现 ≥3 次（说明它在脑子里占着工位）

反证义务：如果笔记里存在与某价值矛盾的行为，必须写出来。价值不是非黑即白的，允许"我在意但做不到"。

## 二、十种价值类型（Schwartz 基本价值观，用于归类命名）

| 类型 | 核心 | 在笔记里的典型表达 |
|---|---|---|
| 自我导向 | 独立判断、创造、自由 | 讨厌被安排、想自己定规则 |
| 刺激 | 新鲜、冒险、变化 | 厌倦重复、想换环境 |
| 享乐 | 当下的愉悦与舒适 | 拒绝内耗、想休息、享受小事 |
| 成就 | 通过能力获得认可 | 在意结果、比较、"没白过" |
| 权力 | 地位、控制、资源 | 在意话语权、被不被重视 |
| 安全 | 稳定、秩序、可预期 | 怕风险、要退路、储蓄 |
| 遵从 | 遵守规范、不越界 | 怕给别人添麻烦、守规矩 |
| 传统 | 传承、承诺、责任 | 对家人、对长期关系的义务 |
| 仁善 | 身边人的福祉 | 照顾具体的人、不忍心 |
| 普世 | 更大的群体与原则 | 公平、环保、公共议题 |

**用法**：一条价值必须落到具体类型上，不许停在"你在意成长"。如果笔记里的表述和类型不符，就用笔记里的原词。
相邻类型兼容（安全-遵从-传统），**对角类型互斥**（安全 vs 刺激、成就 vs 仁善、权力 vs 普世）——互斥对出现就是内耗来源。

## 三、排序方法：强制两两比较

不要按"出现次数"排序（会被话题热度误导）。用这个规则：
对任意两条价值 A、B 问：**如果必须放弃一个，你会放弃哪个？**
答案必须能从笔记里找到依据（哪次选择的代价更大）。

输出排序时，给出"声明排序"和"实际排序"两列，差异本身就是洞察。

## 四、输出结构（严格照此）

每条价值：
1. **命名**：一个具体的词（可带括注，如"成就（被看见的那种）"）
2. **类型**：对应上表哪一类
3. **证据**：2-3 条原文 + 日期，注明命中哪条证据链（时间/情绪/金钱/重复）
4. **实际排序**：第 N 位，理由是放弃了什么
5. **代价**：为了守住它，你在牺牲哪条价值

收尾必须是一句**给用户自己填的问题**，不许替他回答，不许给建议。

## 五、常见错误（不许犯）

- 把"应该在意"写成"在意"（例：把"想陪家人"写成重视家庭，但笔记里全是给钱不给时间）
- 用大词（成长、自由、意义）代替具体类型
- 把情绪当作价值（"你很焦虑"不是价值，"你在意不可控风险"才是）
- 输出十条价值。3-5 条就够，多了等于没有排序
